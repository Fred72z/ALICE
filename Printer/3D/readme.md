# Boîtier 3D #

Le boîtier est en 2 parties. La partie inférieure est identique pour toutes les versions.

Pour la partie supèrieure il y a 3 fichiers :

- version MC10 (pas de tite Alice en bas)
- version pour imprimante monofilament (monochrome)
- version pour imprimante multifilament en 2 fichiers : color_sup et color_sup_texte
